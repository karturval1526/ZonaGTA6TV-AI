# ZonaGTA6TV V13 — News Radar

## Flujo
1. Abre `index.html` en Chrome.
2. Carga la IA local si quieres generación automática.
3. En **NEWS RADAR GTA 6**, pulsa **BUSCAR AHORA**.
4. Elige una noticia y pulsa **CREAR CONTENIDO**.
5. La app pasa el titular, resumen, fuente y enlace al generador.
6. Revisa el resultado, genera imágenes/voz/video y descarga el paquete.

## Importante
El radar usa feeds públicos mediante proxies CORS. La disponibilidad de una fuente puede variar. Una filtración nunca debe presentarse como confirmada sin corroboración.

La app no publica automáticamente en YouTube ni intenta evadir verificaciones.
