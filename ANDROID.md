# ZonaGTA6TV AI Factory — Android

## Instalación rápida

1. Sube esta carpeta a GitHub Pages, o publícala en cualquier hosting HTTPS.
2. Abre la página con Google Chrome en Android.
3. Espera a que aparezca **Instalar**.
4. Pulsa **Instalar**.
5. La app aparecerá en la pantalla de inicio como una aplicación.
6. Abre la app y pulsa **Cargar IA gratuita**.

## Requisitos

- Android moderno.
- Google Chrome actualizado.
- WebGPU disponible.
- Espacio libre suficiente para descargar el modelo local.
- La primera carga necesita Internet para descargar el runtime/modelo. Después, el navegador puede reutilizar la caché según sus políticas.

WebLLM requiere un navegador compatible con WebGPU y ejecuta la inferencia en el navegador.

## Importante

Esta aplicación NO usa:
- OpenAI API
- claves privadas
- OAuth de YouTube
- pagos por tokens
- servidor de IA

La IA se ejecuta localmente en el teléfono.

## Qué puede hacer

- Guiones de Shorts
- Guiones largos
- Hooks
- Títulos
- Descripciones
- Hashtags
- Keywords
- Storyboards
- Subtítulos SRT
- Biblioteca de proyectos
- Exportación de paquetes de producción

## Limitación de Android

El modelo local consume memoria y batería. Si el teléfono tiene poca memoria, la generación puede ser lenta o Chrome puede cerrar la pestaña. En ese caso se puede cambiar a un modelo aún más pequeño.

## Para instalar desde GitHub Pages

En GitHub:
Settings → Pages → Deploy from branch → main → / (root).

Luego abre la URL HTTPS desde Chrome Android.
