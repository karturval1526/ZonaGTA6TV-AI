# ZonaGTA6TV V14 — Smart News Factory

## Flujo
1. Abre `index.html` en Chrome.
2. Pulsa **BUSCAR AHORA**.
3. El radar agrupa noticias parecidas y reduce duplicados.
4. **CREAR SHORT + LARGO** carga la historia en el generador.
5. Genera guion, voz, imágenes y video.
6. Para un Short usa 9:16; para video largo usa 16:9.
7. Pulsa **CREAR PAQUETE DE PUBLICACIÓN** para descargar un ZIP con video, metadata, guion, subtítulos, fuentes y checklist.

## Importante
- Las filtraciones/rumores se etiquetan como no confirmados.
- Revisa las fuentes antes de publicar.
- La app no sube contenido a YouTube de forma silenciosa. La publicación requiere tu autorización mediante YouTube Studio/API.
- El render depende de las capacidades de Chrome y del teléfono.
